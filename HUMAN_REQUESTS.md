# Human Requests

Only the Mastermind writes final requests to the Human Operator. This file is
the central index of final human requests; each entry links to the full
task-specific request at `work/tasks/<task-id>/human-request.md`.

Specialist agents may propose human requests in their handoffs, but the Mastermind decides whether to ask.

## Request Format

```text
YYYY-MM-DD HH:MM | Request ID | Task Request | Requested By | Reason | Exact Human Action | Inputs To Provide | Status | Result
```

## Requests

```text
none | H-000 | none | Mastermind | none | No pending human requests | none | closed | none
```

## Request Quality Bar

A human request must be final and actionable. Do not ask the Human Operator to interpret internal agent debate. Ask for one concrete external action, approval, upload, screenshot, credential, account action, or design-tool run.
